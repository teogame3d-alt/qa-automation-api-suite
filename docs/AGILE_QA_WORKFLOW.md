# Agile QA Workflow

## Sprint Planning

- Review user stories, acceptance criteria, and technical design notes.
- Identify testable requirements and open questions.
- Estimate testing effort by risk, complexity, and regression impact.
- Prioritize smoke, regression, API, and negative-path checks.

## During Development

- Collaborate with developers and QA team members.
- Review implementation notes and clarify expected behavior.
- Update automated tests when requirements change.
- Track defects with clear steps, expected result, actual result, and evidence.

## Retrospective

- Review escaped defects and flaky tests.
- Improve test coverage for repeated issues.
- Refine test data, fixtures, and reporting.
- Identify framework improvements for the next sprint.
