# QA Metrics

## Metrics I Would Track

- Automated test count by type: smoke, contract, regression, negative-path.
- Pass/fail status in CI.
- Defects found by severity.
- Reopened defects.
- Test execution time.
- Flaky tests.
- Coverage of critical API flows.
- Requirements with automated checks.

## Why These Metrics Matter

QA metrics help the team understand risk, progress, and quality trends. They also support sprint planning, regression prioritization, and communication with developers and product stakeholders.
